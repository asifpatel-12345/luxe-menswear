# LUXE MENSWEAR - Bespoke Collection Web Application

A modern, responsive, luxury-themed e-commerce user interface built for **LUXE MENSWEAR**[cite: 1]. The interface features a dark aesthetic with gold accents, category filtering, search capabilities, and a showcase for bespoke menswear collections[cite: 1].

![LUXE MENSWEAR Preview](https://via.placeholder.com/1200x600?text=LUXE+MENSWEAR+Preview)

---

## 🌟 Key Features

- **Luxury Aesthetics**: Dark mode design (`#0c0c0c`) paired with gold typography accents for an exclusive brand identity[cite: 1].
- **Responsive Layout**: Fully responsive grid layout optimized for mobile, tablet, and desktop viewports.
- **Top Announcement Bar**: Highlights global shipping offers and concierge services[cite: 1].
- **Interactive Toolbar**: Category filter pills and a quick-search input bar for intuitive collection navigation[cite: 1].
- **Product Cards**: Displays product badges (*Bestseller*, *New Arrival*, *Limited Edition*), wishlist interaction buttons, images, and pricing[cite: 1].

---

## 🛠️ Built With

- **HTML5**: Structural markup.
- **Tailwind CSS**: Utility-first CSS framework (via CDN) for styling and layout management.
- **Google Fonts**:
  - *Playfair Display* (Serif headings)
  - *Inter* (Clean sans-serif body text)
